# Audio Folder

Silakan masukkan file audio atau musik background untuk website di dalam folder ini.
Pastikan nama file sesuai dengan yang diatur di dalam kodingan. 

Secara default, kodingan menggunakan:
**`music.mp3`**

(Jika nama file berbeda, ubah nama file menjadi `music.mp3` atau ubah kodingan di `src/components/MusicController.tsx`).
