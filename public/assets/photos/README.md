# Photos Folder

Silakan masukkan foto-foto kenangan di dalam folder ini.

Pastikan nama file sesuai dengan yang diatur di dalam kodingan:
- **`photo1.jpg`**
- **`photo2.jpg`**
- **`photo3.jpg`**
- **`interactive.jpg`** (Untuk bagian foto yang bisa di-tap/ditekan)

Jika ingin menambahkan lebih banyak foto, silakan edit file `src/components/MemoryScroll.tsx` dan tambahkan ke dalam list `MEMORIES`.
